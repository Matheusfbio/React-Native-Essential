# Política de Segurança

## Reportando Vulnerabilidades

Se você descobrir uma vulnerabilidade de segurança, por favor **NÃO** abra uma issue pública.

Em vez disso, envie um email para: [seu-email@exemplo.com]

Inclua:
- Descrição da vulnerabilidade
- Passos para reproduzir
- Impacto potencial
- Sugestões de correção (se houver)

## Versões Suportadas

| Versão | Suportada          |
| ------ | ------------------ |
| 1.0.x  | :white_check_mark: |

## Atualizações de Segurança

Vulnerabilidades de segurança serão corrigidas com prioridade e uma nova versão será lançada o mais rápido possível.

# Contribuindo para React Native Essential

Obrigado por considerar contribuir com o projeto! 

## Como Contribuir

1. Faça um fork do projeto
2. Crie uma branch para sua feature (`git checkout -b feature/MinhaFeature`)
3. Commit suas mudanças (`git commit -m 'Adiciona MinhaFeature'`)
4. Push para a branch (`git push origin feature/MinhaFeature`)
5. Abra um Pull Request

## Padrões de Código

- Use TypeScript
- Siga as convenções do ESLint configuradas no projeto
- Escreva código limpo e legível
- Adicione testes quando apropriado
- Use Conventional Commits (veja [CONVENTIONAL_COMMITS.md](CONVENTIONAL_COMMITS.md))
- Execute `npm run lint` e `npm run format` antes de commitar

## Reportando Bugs

Ao reportar bugs, inclua:
- Descrição clara do problema
- Passos para reproduzir
- Comportamento esperado vs atual
- Screenshots (se aplicável)
- Ambiente (OS, versão do Node, etc)

## Sugestões de Features

Abra uma issue descrevendo:
- O problema que a feature resolve
- Como você imagina que funcione
- Exemplos de uso

## Processo de Review

- Todas as contribuições passam por code review
- Mantenha PRs focados e pequenos
- Responda aos comentários de forma construtiva

# React Native Essential

Um aplicativo React Native desenvolvido com Expo Router, focado em fundamentos essenciais do desenvolvimento mobile.

## 🚀 Tecnologias

- React Native 0.81.5
- Expo SDK 54
- Expo Router 6
- TypeScript
- Supabase
- React Hook Form

## 📋 Pré-requisitos

- Node.js
- npm ou yarn
- Expo Go app (no seu dispositivo móvel)

## 🔧 Instalação

```bash
# Clone o repositório
git clone <url-do-repositorio>

# Entre no diretório
cd React-Native-Essential

# Instale as dependências
npm install

# Inicie o projeto
npm start
```

## 📱 Executando

```bash
# Inicia o servidor Expo
npm start

# Escaneie o QR code com:
# - Expo Go (Android)
# - Camera app (iOS)

# Ou execute no navegador
npm run web
```

## 🧪 Testes

```bash
npm test
```
